Before using AI

Checking the teaching connection…

Direct value editing and playback work without an API key. AI interpretation needs the teaching server.

Start the local AI server

From the project directory, run:

node teaching-launcher.js --ai --port=8002

Enter your key at the hidden prompt, then open this catalog on port 8002. Keep the terminal open.

Both versions remain separate so you can compare their teaching experience before choosing what to publish.
